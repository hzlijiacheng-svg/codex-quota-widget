额度与节奏 v2.1.0
=================

功能
----
- 菜单栏用两块电池和百分比分别展示 Codex 周额度、ZCode 企业网关额度。
- 点击菜单栏可切换查看额度、重置时间、使用速度和 Token 信息。
- 平均速度按额度周期内的周一至周五全天计算；1.00× 表示均匀节奏。
- Codex 显示剩余工作日和平均每天可用额度；法定节假日和调休暂未识别。
- 带 Touch Bar 的 Mac 显示 Codex 周额度、重置时间与工作日平均速度。
- 每 5 分钟刷新额度，也可在面板中手动刷新。

安装
----
1. 确认电脑已安装并登录 ChatGPT/Codex，或已登录 Codex CLI。
2. 双击“安装.command”。
3. 如果 macOS 提示无法验证开发者，右键点击“安装.command”，选择“打开”。
4. 安装完成后工具会启动，之后登录 macOS 时自动运行。

ZCode 企业网关
---------------
网关额度需要另行配置只读查询。未配置时，Codex 额度仍可使用。
配置方式见源码中的 README；网关数据对应配置的消费者和额度规则。

Token 统计与隐私
----------------
首次启动会在后台扫描近期 Codex 会话日志，之后只读取新增内容。统计只解析
token_count 数值，不读取提示词、回复或代码正文。企业网关查询使用本机配置的
只读凭据，对 APIG 管理接口发送签名请求；凭据不包含在安装包中。

卸载
----
双击“卸载.command”。应用和登录启动项会移到废纸篓；Touch Bar 恢复原有模式。

适用范围
--------
- 构建目标为 macOS 12 及以上，安装包同时包含 Intel 和 Apple 芯片架构。
- 当前没有 Windows 版本。
- 安装包使用本地签名，没有 Apple Developer ID 公证，首次打开可能出现系统提示。
