Codex 额度仪表 v2.0.1
======================

作用
----
在 macOS 顶部菜单栏持续显示 Codex 周额度：
- 一条细血条 + 带 % 的剩余额度数字
- 点击后查看全部额度窗口、重置倒计时和今日 Token 消耗
- 三个圆环对比本周时间、工作日进度和额度已用，并给出节省/富余建议
- 今日节奏会说明比近 7 日同时段均值多/少多少 Token
- 带 Touch Bar 的 Mac 会显示周额度长血条、剩余/已用百分比、重置倒计时和当前节奏；没有的数据窗口不会显示
- 每 5 分钟刷新额度，每分钟更新倒计时
- 自动尝试环境代理、macOS 系统代理和直连，无需配置文件

安装
----
1. 确认电脑已安装并登录 ChatGPT/Codex，或已登录 Codex CLI。
2. 双击“安装.command”。
3. 如果 macOS 提示无法验证开发者：右键点击“安装.command”，选择“打开”，再确认一次。
4. 安装完成后会立即启动，并在以后登录 macOS 时自动运行。

Touch Bar 说明
---------------
应用运行时会临时使用“App 控件 + 控制条”模式：额度显示在左侧，亮度、音量等系统按钮保留在右侧。退出或卸载应用后，会恢复原来的 Touch Bar 模式。

首次 Token 统计
----------------
工具第一次启动时会在后台扫描最近 8 天的本地 Codex 日志。日志较多时可能需要几十秒；菜单栏额度会先显示，不需要等待扫描结束。之后只读取新增日志。

菜单栏空间不足
--------------
如果额度项目没有显示：
1. 切换到 Finder，让左侧应用菜单变短。
2. 找到带“血条、百分比”的额度项目。
3. 按住 Command，把它拖到菜单栏右侧。

按钮说明
--------
- “统计口径”：解释额度和今日 Token 节奏如何计算。
- “在 Finder 中打开日志目录”：只打开 ~/.codex/sessions，不会修改或上传日志。
- “立即刷新”：立即重新读取额度，并检查新增 Token 日志。

卸载
----
双击“卸载.command”。应用和登录启动项会移到废纸篓。

数据与隐私
----------
- 额度来自本机 Codex app-server。
- Token 统计只解析会话日志中的 token_count 数值，不解析提示词、回复或代码正文。
- 不保存、不展示、不上传账号令牌，所有统计只在本机完成。

适用范围
--------
- macOS 12 及以上
- Intel 和 Apple 芯片 Mac
- 当前只启用 Codex；GLM/公司 AI 网关适配等待管理接口确认
- 展示的是 Codex 账户额度，不是 ChatGPT 网页版各模型的消息上限

内部工具说明
------------
当前安装包使用临时本地签名，没有 Apple Developer ID 公证，因此首次打开可能出现系统安全提示。
